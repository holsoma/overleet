# Attribution and source policy

OVERLEET's original code, questions, explanations and examples use the MIT licence. This licence does not relicense linked documentation, articles, papers or other people's exercises.

The initial collection refers to scikit-learn documentation, Google Machine Learning Crash Course, the NIST statistical handbook, SciPy documentation, Penn State statistics teaching materials, Microsoft experimentation articles and the original Attention, RAG and LoRA papers. Per-question references identify the relevant work and access date. Explanations are newly written; source prose, figures and exercises are not reproduced.

The weekly collector stores feed titles and URLs from Google Research and the scikit-learn blog, plus links to reviewed GitHub documents. The LoRA repository is MIT licensed; feed availability does not establish a licence to republish article text. The reviewed source registry records these boundaries.

The expanded bank uses [Youssef Hosni's interview-question repository](https://github.com/youssefHosni/Data-Science-Interview-Questions-Answers) and the [GeeksforGeeks data science interview article](https://www.geeksforgeeks.org/data-science/data-science-interview-questions-and-answers/) to identify broad topic coverage. They are discovery references, not sources of reusable answer text. No repository licence was identified for the former on 15 October 2026. GeeksforGeeks reserves rights under its [intellectual property policy](https://www.geeksforgeeks.org/legal/intellectual-property-rights-legal/). OVERLEET does not copy their question wording, answer text, examples or ordering. The new questions and explanations are independently written and cite primary technical references. The GeeksforGeeks HTML page is reviewed manually because the automated collector accepts only registered RSS/Atom feeds and GitHub documents.

The interface uses Radix primitives, shadcn/ui component conventions, Lucide icons, React Markdown and KaTeX through their package dependencies. Their package licence files remain authoritative. The locally owned Button component follows the MIT-licensed shadcn/ui convention.

For new sources, record the exact URL and the permitted use. Prefer original explanations grounded in primary references. If reuse permission is unclear, link to the source and do not copy its text or images. Do not infer that a company asks an interview question because its researchers published related work.
