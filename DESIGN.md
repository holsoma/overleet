# OVERLEET visual system

The agreed dark interface supports a candidate reading questions and writing explanations during an evening study session. Use a restrained charcoal palette with a muted lime accent for current navigation and primary actions. Keep neutral colours slightly tinted.

Use system sans-serif text, tabular numerals for counts and a monospace wordmark. The desktop shell has a slim navigation rail and a wide question table. A single daily-question strip sits above the table. Give each page one clear title, without promotional eyebrows, repeated section titles or sidebar slogans. The question view has two reading/writing columns, stacked on small screens. Avoid large marketing headlines, gradients, glass, decorative charts and nested cards.

Use 1px separators, restrained corner radii and a 4px spacing base. Question titles, answers, rubric checkpoints and dashboard topic links use 16px equivalent text, with 13px metadata and at least 14px form values, expressed in rem. Keep answer prose within 65-75ch. Do not shrink reading text on mobile. Constrain the desktop content width and keep related controls close together; larger screens must not add empty table-row padding. Show topics as wrapping buttons, with search and compact sorting. Put remaining filters in one accessible disclosure and show removable active filters outside it. Omit the company selector when there are no company tags. Keep source attribution accessible through a disclosure, without displacing the response editor. Show browser/account storage information once beside the relevant controls. Aim for 44px interactive controls. State transitions are brief, respect reduced motion and never delay input. Provide consistent focus, hover, disabled, loading and error states.
