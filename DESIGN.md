# OVERLEET visual system

The agreed dark interface supports a candidate reading questions and writing explanations during an evening study session. Use a restrained charcoal palette with a muted lime accent for current navigation and primary actions. Keep neutral colours slightly tinted.

Use system sans-serif text, tabular numerals for counts and a monospace wordmark. The desktop shell has a slim navigation rail and a wide question table. A single daily-question strip sits above the table. Filters use ordinary labelled controls. The question view has two reading/writing columns, stacked on small screens. Avoid large marketing headlines, gradients, glass, decorative charts and nested cards.

Use 1px separators, restrained corner radii and a 4px spacing base. Question titles and answer prose use 16px equivalent text, with 13px metadata and 14px form values, expressed in rem. Keep answer prose within 65-75ch. Do not shrink reading text on mobile. Constrain the desktop content width and keep related controls close together; larger screens must not add empty table-row padding. Keep search, topic, difficulty and sorting visible, with secondary filters in an accessible disclosure that shows active filters. Omit the company selector when there are no company tags. Aim for 44px interactive controls. State transitions are brief, respect reduced motion and never delay input. Provide consistent focus, hover, disabled, loading and error states.
